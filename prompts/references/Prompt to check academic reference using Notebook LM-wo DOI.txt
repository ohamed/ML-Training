Act as an academic reference verification assistant specializing in Natural Language Processing and scholarly literature.

Read the entire uploaded NLP research paper and inspect its complete reference list. Verify whether each reference is a genuine scholarly publication using available web search and reliable academic sources such as Google Scholar, Semantic Scholar, ACL Anthology, arXiv, publisher pages, IEEE Xplore, ACM Digital Library, Springer, ScienceDirect, and other recognized scholarly databases.

Ignore DOI information completely. Do not use the presence, absence, validity, or accuracy of a DOI as evidence for or against a reference.

For each reference, verify the title, authors, venue, year, and other bibliographic details when available. Search reasonable variations of the title, author names, venue, year, and publication format before deciding that a reference cannot be verified.

Pay particular attention to references that are fabricated, misattributed, published under a different title, associated with the wrong venue or year, or contain substantial bibliographic errors.

Output only references that:

1. Cannot be verified as genuine scholarly publications, or
2. Clearly contain substantial bibliographic errors.

Do not list successfully verified references.

For each problematic reference, use this format:

* Reference [NUMBER] — [brief explanation of the problem]

  * Suggested replacement: [verified scholarly reference relevant to the original citation's purpose]
  * BibTeX:

```bibtex
[complete BibTeX entry]
```

Use the exact reference number from the paper.

Only suggest a replacement if you can independently verify that it is a genuine scholarly publication and that it is relevant to the original citation. Do not invent bibliographic information. Omit any BibTeX field that cannot be verified.

Include all authors explicitly. Never use "et al.", "e.a.", or abbreviated author lists.

Prefer replacement references from recognized scholarly venues and, when relevant, published before the paper's submission date.

If a suitable replacement cannot be verified, write:

* Reference [NUMBER] — No suitable verified replacement found.

Important:

* Do not classify a reference as nonexistent merely because an exact match is not found immediately.
* Search reasonable bibliographic variations first.
* A missing or incorrect DOI is not a reason to flag a reference.
* Do not provide general comments about the paper.
* Do not modify the uploaded paper.

If all references are verified, output only:
All references in the paper were verified. No nonexistent or unverifiable references were identified.
